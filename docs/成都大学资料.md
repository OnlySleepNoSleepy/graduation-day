## 二、20 个学院与 72 个本科专业

> 游戏里按这份清单做「先选学院、再选专业」。

### 工科

**机械工程学院**
机械设计制造及其自动化（国家级一流）、材料成型及控制工程（省级一流）、材料科学与工程、车辆工程、机械电子工程

**电子信息与电气工程学院**
自动化（国家级卓越工程师、省级一流）、电子信息工程（省级一流）、通信工程、电气工程及其自动化

**计算机学院**
计算机科学与技术（国家级一流）、软件工程（国家级卓越工程师、省级一流）、物联网工程、数据科学与大数据技术

**食品与生物工程学院、化学化工学院**
食品科学与工程（国家级一流）、食品质量与安全（省级一流）、生物工程（省级一流）、化学

**建筑与土木工程学院、应急管理学院**
土木工程（国家级一流）、环境工程、工程管理、工程造价、测绘工程、建筑学、应急技术与管理、安全工程

### 医学

**医学中心**
临床医学（五年制）、护理学、口腔医学技术、医学检验技术

**药学院**
药学（国家级一流）、制药工程（省级一流）、药物制剂

### 经管

**商学院**
会计学（国家级一流）、工商管理（国家级一流）、财务管理、国际经济与贸易、审计学、金融科技

**旅游与文化产业学院**
旅游管理（国家级一流）、会展经济与管理（省级一流）、文化产业管理、酒店管理

### 人文

**文学与新闻传播学院**
汉语言文学（国家级一流）、广播电视学、汉语国际教育、网络与新媒体

**外国语学院**
泰语（省级一流）、英语、商务英语

**法学院**
法学（国家级一流）、社会工作

**马克思主义学院**
思想政治教育

### 师范

**师范学院**
学前教育（国家级一流）、小学教育（省级一流）、应用心理学、特殊教育

**体育学院**
体育教育（国家级一流）、社会体育指导与管理（省级一流）、休闲体育

**音乐与舞蹈学院**
音乐表演、舞蹈表演、音乐教育

### 艺术

**美术与设计学院**
视觉传达设计（国家级一流）、绘画（省级一流）、产品设计、环境设计

**影视与动画学院**
动画（国家级一流）、广播电视编导（国家级一流）、数字媒体技术、数字媒体艺术

### 中外合作

**斯特灵学院**（与英国斯特灵大学合办）
休闲体育（中外合作）、数据科学与大数据技术（中外合作）、网络与新媒体（中外合作）

**海外教育学院**
电气工程及其自动化（中外合作办学）

## 四、特色平台与“成大标签”

这些是别的高校没有的，写剧情时优先用：

1. **大运村**——2021 年第 31 届世界大学生夏季运动会运动员村就办在校内，学生当过志愿者。
2. **张澜学院**——拔尖创新人才培养基地，大二有选拔，进去了课表完全不一样。
3. **新华三 IT 学院**——计算机学院与企业共建，实习名额多。
4. **肉类加工四川省重点实验室**——食品学院的招牌，川味肉制品，上过《中国食品报》。
5. **四川抗菌素工业研究所**——国家级平台，药学、制药的底气。
6. **成都足球学院 / 蹼泳专项**——体育学院，2026 年才设蹼泳专项，学生拿了世界杯铜牌。
7. **中国-东盟艺术学院**——美术、影视动画、音乐舞蹈三院合一，还有东盟美术馆。
8. **斯特灵学院**——与英国斯特灵大学合办，中英双学位，学费和课表都是双份的。
9. **四川省泰国研究中心**——外国语学院泰语专业的靠山。
10. **附属小学、附属幼儿园**——师范学院实习就在校内。
11. **CC 空间**——国家级众创空间，创业项目孵化。
12. **“至善杯”校园马拉松**——真有其事，每年办，会封路。

## 五、映射到游戏的方式

| 真实 | 游戏内 |
|---|---|
| 成都大学 | 蓉城大学（校名虚构，其余照实） |
| 成洛大道 2025 号 | 同址，地铁 4 号线「蓉大站」 |
| 大运村 | 保留，写成“学校当过世界大学生运动会的运动员村” |
| 张澜学院 | 写成“拔尖班选拔”，大二一次机会 |
| 新华三 IT 学院 | 写成“和某家 IT 大厂共建的学院”，实习直通 |
| 肉类加工重点实验室 | 食品专业的专属事件场景 |
| 附属医院 | 医学专业实习与规培 |
| 东盟美术馆 / 音乐厅 | 艺术专业的展演场景 |
| 中国-东盟艺术学院 | 保留原名 |
| 斯特灵学院 | 写成“和英国某大学合办的学院” |
| 各专业的开设年份 | **设定值，非官方数据**（用于“某几年还没这个专业”），见 `GD.MAJOR_SINCE` |

**一键切换真实校名**：`src/data_core.js` 里的 `GD.SCHOOL` 常量，改成「成都大学」即可，其余不用动。

## 六、后续内容补充的原则

1. 专业、学院、建筑编号、场馆名称，一律照本文件，不要自己编。
2. 可以编的是：具体的人（室友、老师、同学）、具体的事（哪门课难、哪个食堂好吃）。
3. 不写真实师生姓名，不评价具体院系好坏，考试政策保持模糊。
4. 新事件优先挂在“成大标签”上（第四节），那是这所学校最不容易撞车的地方。
