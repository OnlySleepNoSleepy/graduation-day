# 《蓉大四年》设计文档 v0.1

> 一款单文件网页的文字养成小游戏：一名大一新生在蓉城大学度过八个学期，最终走向毕业时的去向。
> 单局 8 分钟 · 50 条事件 · 8 种结局 · 零依赖、双击即玩。

---

## 1. 一句话定位

你带着一张录取通知书来到成都东郊，四年后带走一张毕业证——中间这八学期，每一次「去图书馆还是去打球」，都在悄悄决定你毕业那天的样子。

**体验目标**：让人在 8 分钟内经历一次「如果当年我……会怎样」的假设，并在结局页愣一下。

---

## 2. 世界观与舞台

- **学校**：蓉城大学（虚构），成都东郊十陵一带，校门口是地铁 4 号线「蓉大站」。
- **校园地标**：南门、青涟湖、一食堂与二食堂、图书馆四楼靠窗位、老操场、快递站、后街。
- **周边**：青龙湖、古镇、春熙路、熊猫基地、人民公园。
- **时间**：主角 2022 年 9 月入学，2026 年 6 月毕业。
- **真实感来源**：成都的阴天、回南天似的潮、火锅与串串、地铁早高峰、期末周的图书馆、亲戚在年夜饭上的那句「毕业了打算干啥」。
- **虚构声明**：校名、院系、人物均属虚构，如与雷同纯属巧合（游戏内标注一句）。

---

## 3. 核心循环

```
入学 → [第 1 章：大一上] → … → [第 8 章：大四下] → 结局
              ↑
        每章固定结构：
        ① 主线剧情（1 次关键抉择）
        ② 随机事件（1 条，从池中抽，带 2 个选项）
        ③ 行动点 ×2（从 7 种行动中选 2 次）
        ④ 学期结算（属性变动、挂科检查、学期小结一句话）
```

一章约 60 秒，八章约 8 分钟。所有选择立即结算，不设「读档反悔」。

## 4. 八章时间表

| 章 | 学期 | 主线节点 | 关键抉择 |
|---|---|---|---|
| 1 | 大一上 | 军训、百团大战 | 加哪个社团：学生会 / 技术社团 / 吉他社 / 都不加 |
| 2 | 大一下 | 第一次期末周、四级报名 | 四级考不考、要不要开始卷绩点 |
| 3 | 大二上 | 转专业的机会 | 转去「更好就业」的专业 / 留在原地 |
| 4 | 大二下 | 第一次实习面试 | 翘课去实习 / 老老实实上课 |
| 5 | 大三上 | **方向抉择（全局最关键）** | 考研 / 考公 / 直接就业 / 再想想 |
| 6 | 大三下 | 闭关 or 实习 | 暑假留校备考 / 去公司实习 |
| 7 | 大四上 | 秋招 / 考研初试 / 国考 | 三线同时压来，只能押注 |
| 8 | 大四下 | 复试 / 省考 / 春招 / 答辩 | 最后一搏，然后毕业 |

第 5 章选定「方向」，决定后续章节的事件池与结局判定口径。

## 8. 结局判定（8 种，自上而下匹配）

| 结局 | 判定条件 | 基调 |
|---|---|---|
| 撑不住了 | 心情 ≤ 0 | 沉重，但不指责 |
| 延期毕业 | 挂科 ≥ 3 | 平静的自嘲 |
| 保研上岸 | GPA ≥ 3.6 且 履历 ≥ 35 | 少年得志 |
| 考研上岸 | 方向=考研 且 考研分 ≥ 60 | 苦尽甘来 |
| 公务员 | 方向=考公 且 考公分 ≥ 60 | 踏实 |
| 大厂 offer | 就业分 ≥ 55 | 光鲜里带疲惫 |
| 教师编 / 国企 | 就业分 ≥ 40 | 稳妥 |
| 待业 / 慢就业 | 以上都不满足 | 不悲情，留一点亮 |

**派生分公式（v0.2 已实装，全部归一化到 0–100）**

```
考研分 = 绩点率×0.35 + 英语×0.25 + 备考×0.30 + 心情×0.10     需 ≥ 74
考公分 = 备考×0.40 + 技能×0.20 + 英语×0.15 + 人脉×0.10
        + 心情×0.05 + 绩点率×0.10                              需 ≥ 70
就业分 = 技能×0.35 + 履历×0.35 + 人脉×0.15 + 绩点率×0.15
        大厂 ≥ 60 / 教师编或国企 ≥ 43
保研   = 绩点 ≥ 3.55 且 履历 ≥ 28，且方向为「考研」或「还没定」
```

**临场发挥**：考研、考公的最终分再乘一个 0.91–1.09 的随机系数（复试 / 面试的运气），就业乘 0.94–1.06。结算页显示的就是乘过之后的分，所以数字和结果永远自洽。

结局页包含：结局标题 + 300 字结语 + 四年回顾（3–5 个高光时刻，从玩家实际选择里回捞）+ 属性成绩单 + 「再来一次」。

## 9. 界面与美术

- **风格**：纸质手账 / 学生证内页。米白纸底、淡横线、印章红点缀、宋体与楷体混排。
- **画面**：纯 CSS + emoji，不引用任何外部图片，保证离线可用与零版权风险。
- **动效**：翻页过渡、文字逐字出现（可跳过）、属性变动浮字。
- **适配**：桌面居中卡片；手机竖屏单列，按钮大手指可点。
- **音效**：默认关闭，提供一个开关，用 WebAudio 合成点击音（无外部音频文件）。

## 10. 技术实现

- 单文件 `index.html`，内联 CSS 与 JS，约 2000–2500 行，无任何依赖与网络请求。
- 数据与逻辑分离：`EVENTS` / `ACTIONS` / `ENDINGS` 三个常量对象，便于后期加内容。
- 存档：`localStorage` 自动存当前进度，刷新不丢；结局后可一键重开。
- 结构：`state` 单一数据源 → `render()` 全量重绘 → 事件绑定。够简单，够稳。

## 13. v0.2 实装记录（已完成）

**已拍板**：游戏名《毕业那天你会去哪》；专业按成都大学官网清单做「先选学院、再选专业」，共 **20 个学院 / 74 个本科专业**；恋爱线不设独立系统，投入越深线越重。

**已实现**：8 章主线 + 54 条随机事件 = **62 条事件**；8 种结局；20 学院 74 专业；六大学科门类各有专属事件与结局去向措辞；恋爱线 5 段（可浅可深）；行动点系统；自动存档；手机竖屏适配；单文件约 90 KB，零外部依赖。

**平衡模拟结果**（每策略 1500 局，`tools/sim.js`）

| 策略 | 主要结局 | 占比 | 说明 |
|---|---|---|---|
| 无规划（随机） | 签了 / 还没定 | 60.5% / 35.3% | 不规划也有六成能签一份稳定工作 |
| 考研党 | 考研上岸 | 87.4% | 8.6% 掉到「签了」，3.2% 反而保研 |
| 考公党 | 考公上岸 | 87.6% | 5.8% 掉到「签了」 |
| 就业党 | 拿到 offer | 99.9% | 履历拉满时几乎必中 |
| 保研党 | 推免上岸 | 100% | 绩点 4.0 + 履历 63，门槛 3.55/28 |
| 摆烂党 | 延期毕业 | 100% | 绩点掉到 1.36 |
| 极限党（只学不休） | 考研 65.6% / **撑不住了 16.7%** | — | 心情归零是真实可达的失败线 |

八种结局全部可达；「撑不住了」只在持续透支时出现，属于玩家自己走到的坏结局，不是随机惩罚。

**验证方式**：`node --check` 全部通过；Node 跑 1.5 万局遍历；Edge 无头渲染逐屏截图（封面 / 剧情 / 事件 / 行动 / 结局 / 390px 手机）。

**已知可继续打磨的点**：
1. 结局正文仍是一套通用文案，只有「去向」一行随门类变化；下一步可以按六大门类各写一版结局正文。
2. 恋爱线文案默认对方为「她」，未做性别可选。
3. 没有音效，也没有成就系统。
4. 临床医学按五年制处理：结局页会注明“你还差一年”，但流程仍走四年。

| 生源地 | 成都 / 四川其他 / 重庆 / 西南西北 / 华东华中 | 报到方式旁白、初始人脉与心情、专属事件 |

## 16. v0.5 自由探索 + 全国生源（已完成，现行版本）

### 玩法从「回合制」改成「窗口式自由探索」

原来的流程是「主线 → 随机事件 → 选 2 个行动 → 结算」。现在主线与随机事件保留，但**行动变成了可以自由逛的窗口**：

```
每学期开场（主线抉择 + 1 条随机事件）
        ↓
   ┌─────────── 校园大厅 ───────────┐
   │ 学习 │ 玩 │ 生活 │ 社交 │ 实践 │ 备考* │ 恋爱* │
   └───────────────────────────────┘
        ↓ 点一扇窗
   地点（图书馆 / 空教室 / 宿舍…）
        ↓ 点一个地点
   具体做什么（啃专业课 / 背英语 / 写点自己的东西）
        ↓
   效果弹窗（一句结果 + 属性变化 + 剩余行动点）
```

- **行动点：每学期 3 点，全年 24 点**（原为 2 点 / 16 点，所有数值已按 24 点重新配平）
- 窗口可以自由进出，**返回上一层不消耗行动点**
- 「备考」窗口从大三上（第 5 章）解锁，「恋爱」窗口在恋爱线开始后出现
- 7 个大类窗口、20 个地点、34 件具体的事，每件事都有独立的结果文案和属性效果

- 低于 900 / 1300 / 2000 / 3500 分别带不同的心情修正

## 17. v0.6 事项复用 + 省份三要素（已完成，现行版本）

### 同一件事，在不同地点做，效果不一样

窗口结构固定为 **行动类型 → 地点 → 事项**，但事项不再归属于某一个地点，而是**跨地点复用**：

## 21. v0.9 课程、考勤、竞赛、保研（现行版本）

### 每月必修课程

每月有一门本专业的课，占 **2 小时 + 6 精力**，给一点绩点。每月**8 小时**预算，上课占 2，剩下 6 小时自由安排。

| 师范学院 | 教育学原理 / 心理学基础 / 课程与教学论 / 教师职业道德 |

### 考勤与挂科

- 一学期 6 个月，**缺课 ≥2 个月（≥1/3）判定挂科**
- 挂科 → 下学期自动进入**重修**：时间预算从 8 小时降到 6 小时（2 小时被重修课占用）
- 重修学期仍然缺课 → 再挂一次
- **挂科记录永久保留**，`evaluate` 里直接挡住保研；判方向时也会把“考研”这个选项从第 5 章的选择里删掉

### 竞赛

15 个赛事，分校级 / 省级 / 国家级，按自然月固定开放（如全国大学生数学建模 9 月、挑战杯 3–4 月、CCPC 10–11 月）。

- 每个赛事有固定耗时（4–8 小时）、精力消耗、报名费
- 获奖概率 = 基础概率 × (0.55 + 技能/180 + 履历/260)
- 一等奖 22%、二等奖 40%、三等奖其余；**二等奖及以上**才算“有效竞赛成绩”，进 `awards`
- 拿奖加履历：国家级 +8、省级 +5、校级 +3

**和课程的时间争夺**：国家级比赛要 8 小时，而一个月只有 8 小时且上课要占 2 小时——想打国赛，这个月就得翘课，代价是缺课记录。

### 保研条件（重写）

```
保研 = 无挂科记录
     且 校级及以上二等奖及以上 ≥ 10 个
     且 综测 ≥ 97
     且 方向为「考研」或「还没定」
```

**综测** = 绩点率 × 0.6 + min(获奖数 × 2.5, 30) + 履历 × 0.2（上限 100）。

要凑到 97：绩点接近满、10 个以上的奖、履历还得高。模拟里保研党只有 **44%** 能真的推免，其余落到就业——这个门槛终于配得上“保研”两个字。

1. **考试周**：每学期末有真实的考试场景，成绩由当月投入决定，有紧张感
2. **月度目标**：每月给一个小目标（本月至少去一次图书馆），完成有奖励
3. **事件链**：社团、竞赛、室友关系有连续性，同一件事有后续

一句话场景是低成本的气氛补丁，上面三样才是结构性改造。

```
单科 = 38 + 绩点率×0.32 + min(本学期学习次数,16)×1.4
        + 出勤 6 / 缺勤 −6  − min(缺课次数,4)×5  + 随机(−8..+8)
```

「本学期学习次数」是新埋的计数器：每做一次学习或备考 +1，学期结算时清零。所以**考试考的是这一个学期干了什么，不是历史总绩点**。

每科按分数给等第：90 优 / 80 良 / 70 中 / 60 及格 / 60 以下不及格。

### 后果

- 平均分修正绩点：`+ (平均分 − 78) / 100 × 0.14`
- 平均分 ≥ 85：心情 +4、履历 +1
- 平均分 < 60：心情 −8
- **两科及以上不及格 → 记一次挂科**（和缺课三次并列）

### 实测分档

| 打法 | 平均分 | 班级排名 |
|---|---|---|
| 只上课、不自习 | 70 | 22 / 42 |
| 上课 + 学习 6 次 | 78 | 17 / 42 |
| 认真学 14 次 | 99 | 1 / 42 |
| 逃课 6 次 | 41 | 42 / 42（挂 4 科） |
