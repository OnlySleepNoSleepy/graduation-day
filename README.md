# 毕业那天你会去哪

一个关于四年大学的文字人生模拟游戏。你是蓉城大学（原型：成都大学）2022–2026 级的新生，从报到那天开始，一个回合一个月，走完 48 个月，最后拿到一张成绩单和一个结局。

**🎮 在线试玩：** https://onlysleepnosleepy.github.io/graduation-day/

**📄 单文件版：** [`毕业那天你会去哪.html`](毕业那天你会去哪.html) —— 211 KB，零依赖、零外链、不联网，双击就能玩。

---

## 玩法

- **建档案**：入学年份（2022–2026）、学院与专业（20 个学院 74 个专业）、生源地（34 个省级行政区）、性别、每月生活费
- **一个月一回合**：每月 10 块时间，上课占 1–4 块，剩下的用来学习、玩、生活、社交、实践、竞赛
- **精力**：100 点上限，做事消耗，睡觉吃饭恢复；精力见底会掉心情
- **考试周**：每学期末出一张考卷，成绩由这一学期的投入决定，有班级排名
- **竞赛**：25 个赛事，每个只能参加一次，按你对应的能力决定获奖概率
- **社团**：四个成都大学真实社团，攒活跃度评「十佳社团」
- **参军**：每年上学期首月可报名，服役两年后回来重新选专业
- **毕业设计**：大四写论文，第 48 个月答辩，答辩不过会延毕
- **结局**：8 种，包括保研、考研、考公、大厂、普通就业、延毕、累垮

## 技术

纯前端，单 HTML 文件，**没有任何外部依赖、CDN、图片或音频文件**：

- 界面：手写 CSS，纸张/档案风格
- 插画：14 张手写内联 SVG，三个变体（白天 / 夜晚 / 雨天）
- 音效与音乐：WebAudio 实时合成，按年级变化情绪（大一轻松 → 大四紧张）
- 存档：localStorage

## 本地运行

直接双击 `毕业那天你会去哪.html`。

或者起个静态服务器（开发用）：

```bash
npx serve .
# 打开 http://localhost:3000
```

## 开发

源码在 `src/`，按模块拆成 13 个 IIFE，全部挂在 `globalThis.GD` / `globalThis.RCU` 上。

```bash
# 把 src/*.js 内联进 index.html，产出单文件
node tools/build.js

# 平衡性模拟：8 种策略各跑 N 局，输出结局分布
node tools/sim.js 200
```

目录结构：

```
index.html              开发用的外壳（引用 src/*.js）
毕业那天你会去哪.html     构建产物，可直接游玩
src/
  data_core.js          学校、专业、省份、竞赛、门槛
  data_windows.js       7 个窗口 / 22 个地点 / 66 个事项
  extra_items.js        追加事项
  scenes.js             14 张 SVG 场景插画
  reacts.js             状态旁白
  events_month.js       每月场景短句
  events_main.js        8 章主线
  events_campus.js      校园事件
  events_people.js      室友 / 家人 / 恋爱
  events_more.js        门类与地标事件
  endings.js            8 种结局
  engine.js             状态机、结算、考试、答辩
  ui.js                 渲染、音效、BGM
tools/
  build.js              构建
  sim.js                平衡模拟器
  shots.js              自动截图
docs/
  设计文档.md            完整设计说明（40+ 节）
  成都大学资料.md        学校资料来源与映射
screenshots/            界面截图
```
